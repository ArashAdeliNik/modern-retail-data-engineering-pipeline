## LinkedIn Post

I built a modern end-to-end data engineering pipeline for synthetic retail analytics.

The goal was to go beyond a notebook and demonstrate the engineering controls required for a dependable data product.

The project includes:

• Deterministic daily data generation  
• Explicit validation and rejected-record handling  
• SHA-256 file tracking and idempotent loading  
• Business-key upserts into PostgreSQL  
• Staging and analytical marts with dbt  
• Daily orchestration and retries with Apache Airflow  
• Automated pytest, Ruff, and dbt quality checks  
• A Streamlit dashboard built on modeled warehouse tables  
• Reproducible local execution with Docker Compose  

One of the core design decisions was separating ingestion, transformation, and presentation. Raw records retain source metadata, dbt owns business logic, and the dashboard consumes only tested analytical marts.

All data in the repository is synthetic and generated by the project.
